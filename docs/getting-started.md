# 快速上手指南

> **目标**：从零开始，3 分钟让 ClashEdge 跑起来。

---

## 📥 下载与安装

### Windows 便携版

1. 访问 [Releases](../../releases) 页面
2. 下载最新的 `ClashEdge-portable-win64.zip`
3. 解压到任意目录 (推荐 `D:\ClashEdge` 或 `E:\Tools\ClashEdge`)
   - ⚠️ **避免**解压到 `C:\Program Files`、`C:\Windows` 等需要管理员权限的目录
   - ⚠️ **避免**路径包含中文或特殊字符 (虽然支持，但部分杀毒软件可能拦截)
4. 进入解压目录，双击运行 `ClashEdge.exe`

> **便携版特点**：
> - 无需安装，解压即用
> - 所有数据 (配置、日志、规则) 保存在同目录下 `Data/` 文件夹
> - 整体复制文件夹即可迁移到另一台电脑

### Android 预览版

1. 下载 `ClashEdge-android-<version>.apk`
2. 安装 (需开启"允许安装未知来源应用")
3. 打开应用，授予 VPN 权限
4. **注意**：预览版无真实代理能力，仅可体验 UI 与 VPN 流程

## 🎯 3 步开始使用

### 步骤 1：添加订阅

1. 启动 ClashEdge，左侧导航点击 **「订阅」**
2. 点击右上角 **「添加订阅」** (或点击空状态页的大按钮)
3. 在弹窗中填写：
   - **名称**：自定义，如「我的机场」
   - **订阅链接**：粘贴机场提供的订阅 URL (通常以 `sub://`、`clash://` 或 `https://` 开头)
   - **User-Agent** (可选)：默认自动，特殊机场可自定义
4. 点击「保存」→ 订阅卡片出现，点击卡片右侧「更新」图标获取节点

> **提示**：订阅链接通常在机场官网「一键导入」或「订阅管理」页面获取。

### 步骤 2：启动核心

1. 点击左侧导航 **「首页」**
2. 点击大圆形按钮 **「启动核心」**
3. 等待状态变为 **「已连接」**，显示 mihomo 版本与混合端口

> **首次启动**：Windows 可能弹出防火墙提示，请点击「允许访问」。

### 步骤 3：开启代理

根据需要选择一种模式：

| 模式 | 适用场景 | 操作 |
|------|---------|------|
| **系统代理** | 浏览器、大多数 GUI 应用 | 首页开启「系统代理」开关 |
| **TUN 模式** | 全系统代理、命令行、游戏、容器 | 首页开启「TUN 模式」开关 (需管理员权限) |

> **推荐**：日常使用开启「系统代理」；需要终端/游戏/全局代理时开启「TUN 模式」。

## ❓ 首次使用常见问题

### Q: 启动核心后显示「异常」或「启动失败」
**A**: 常见原因及排查：
1. **端口被占用**：检查 7890/9090/9053 是否被其他代理软件占用 (如 Clash Verge、V2RayN、Shadowrocket 电脑版)
2. **杀毒软件拦截**：将 `ClashEdge.exe` 和 `App/ClashEdge/clash-edge-core.exe` 加入白名单
3. **TUN 驱动未安装**：开启 TUN 模式会自动安装 Wintun，若失败请以管理员身份运行一次
4. **配置损坏**：删除 `Data/config.yaml` 和 `Data/runtime-config.yaml` 重新启动

### Q: 系统代理开启但无法上网
**A**:
1. 检查核心状态是否为「已连接」
2. 尝试切换到「Global」模式测试
3. 检查订阅是否有有效节点 (「代理」页查看)
4. 尝试开启 TUN 模式

### Q: 订阅更新失败 / 节点为空
**A**:
1. 检查订阅链接是否有效 (浏览器打开看是否返回配置)
2. 尝试在订阅编辑对话框修改 User-Agent
3. 查看「日志」页搜索「subscription」相关错误

### Q: 如何完全重置/卸载
**A**: 便携版直接删除整个文件夹即可，无残留注册表/系统文件。

## 🔄 更新 ClashEdge

### 方式 1：应用内更新 (推荐)

1. 「设置」→「关于」→ 点击「检查更新」
2. 发现新版本时点击「下载更新」
3. 下载完成后点击「重启并安装」
4. 应用自动重启，版本号更新

### 方式 2：手动覆盖更新

1. 下载新版 `ClashEdge-portable-win64.zip`
2. 解压**覆盖**原目录 (Data 文件夹会保留，配置不丢失)
3. 重新运行 `ClashEdge.exe`

> **注意**：不要删除 `Data/` 文件夹，它包含你的所有配置、订阅、日志。
