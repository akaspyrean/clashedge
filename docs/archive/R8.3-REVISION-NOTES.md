# ClashEdge v20.26.0808 R8.3 源码修订说明

## 基线

- 基于 CFW v0.20.39 开发版修订。
- 集成 Mihomo v1.19.20。
- 采用便携目录结构：`App`、`Data`、`Other` 与根启动器。

## R8.3 修订

- 版本统一为 `v20.26.0808`。
- 根启动器和应用内层可执行文件统一命名为 `ClashEdge.exe`，清除遗留的旧内层程序命名。
- 统一 Electron 应用名称、Windows 应用标识与启动器显示名称为 `ClashEdge`。
- 自启动使用根启动器并静默启动，不显示主窗口；不额外创建后台服务。
- 统一便携数据目录，启动器同时传递数据路径参数与环境变量，避免产生旧的 `clash-edge` Roaming 数据目录。
- 预处理脚本保留订阅原有的自定义规则和规则集：原规则置于内置分流之前，`MATCH,扶梯出行` 保持最终兜底。
- 移除不再使用的系统 `clash://` 协议注册。
- 保持默认日志级别为“错误”，并保留现有地理数据手动更新与原子替换逻辑。

## 源码结构

- `runtime-source`：应用运行源码、界面与预处理规则。
- `portable-template`：可直接生成的便携程序模板。
- `tools`：启动器、资源打包与 R8 系列补丁工具。

## 构建与校验

1. 在 `runtime-source` 完成修改后，重新生成 `portable-template/App/ClashEdge/resources/app.asar`。
2. 使用 `tools/ClashEdge.Launcher.R8.2.cs` 生成根目录启动器，并确保其目标为 `App/ClashEdge/ClashEdge.exe`。
3. 运行主进程语法校验、预处理规则合并校验和 `mihomo-win64.exe -v`。
4. 打包前检查模板内不存在旧内层程序文件。

## 边界

- 本源码包维持当前经过验证的 Electron 运行时；Electron 43 的安全架构升级应作为独立分支实施并完整回归测试。
- 未包含代码签名；发布前应使用发布者证书对启动器与应用可执行文件签名。
