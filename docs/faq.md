# 常见问题 (FAQ)

> 按类别组织，按需查阅。未覆盖的问题请 [提交 Issue](../../issues/new/choose)。

## 📦 安装与启动

### Q1: 双击 ClashEdge.exe 没反应 / 闪退
**可能原因**：
- 杀毒软件拦截 (火绒、360、Windows Defender 等)
- 路径包含特殊字符导致启动器解析失败
- 缺少 Visual C++ Redistributable (极少见)

**解决**：
1. 将整个 ClashEdge 文件夹加入杀毒软件白名单/信任区
2. 移动到纯英文路径 (如 `D:\ClashEdge`)
3. 以管理员身份运行一次尝试

### Q2: 提示"不是有效的 Win32 应用程序"
**原因**：下载文件损坏或架构不匹配 (ARM64 设备下载了 x64 版本)。

**解决**：重新下载对应架构的 zip 包，校验 SHA256。

### Q3: 首次运行弹出"Windows 保护你的电脑" / SmartScreen 拦截
**原因**：未签名或签名声誉不足。

**解决**：点击"更多信息" → "仍要运行"。或右键文件属性 → 勾选"解除锁定"。

### Q4: 启动后托盘没有图标
**原因**：Windows 托盘区隐藏了图标，或 explorer.exe 重启导致图标丢失。

**解决**：
1. 任务栏右侧"向上箭头"展开隐藏图标区
2. 设置 → 个性化 → 任务栏 → 系统图标 → 打开 ClashEdge
3. 重启 ClashEdge

## 🔌 连接与代理

### Q10: 核心显示"已连接"但无法上网
**排查清单**：
1. 检查模式：尝试切换到 **Global** 模式测试
2. 检查系统代理：设置 → 网络和 Internet → 代理 → 确认"使用代理服务器"开启
3. 检查节点：订阅页确认有节点，代理页确认当前节点延迟正常
4. 尝试开启 **TUN 模式** (需管理员权限)
5. 浏览器清除缓存 / 尝试无痕模式

### Q11: 系统代理开启后，部分应用不走代理
**原因**：
- 应用忽略系统代理设置 (如 Telegram Desktop 需在设置中指定代理)
- 应用使用硬编码代理绕过
- UWP 应用需开启"允许回环" (CheckNetIsolation 或 Fiddler/Clash 配套工具)

**解决**：
- 开启 TUN 模式 (全系统透明代理)
- 或应用内单独配置代理

### Q12: TUN 模式开启失败 / 提示权限不足
**原因**：需要管理员权限安装/加载 Wintun 驱动。

**解决**：
1. 以管理员身份运行 ClashEdge.exe (右键 → 以管理员身份运行)
2. 或在设置 → 代理 → TUN 中开启，程序会自动请求 UAC 提权
3. 企业环境可能组策略禁止安装驱动，需联系 IT

### Q13: 开启 TUN 后无法访问局域网设备 (NAS、路由器后台、打印机)
**原因**：TUN 模式默认接管所有流量，包括局域网。

**解决**：
- 设置 → 代理 → TUN → 添加**排除路由** (如 `192.168.0.0/16`, `10.0.0.0/8`)
- 或临时关闭 TUN，改用系统代理模式访问局域网

### Q14: 连接数很多 / 流量异常大
**排查**：
1. 「连接」页查看活动连接详情，确认是否为预期应用
2. 检查是否有后台自动更新 (Windows Update、游戏平台、云盘同步)
3. 关闭不需要代理的应用，或在规则中添加直连规则

## 🔗 订阅与节点

### Q20: 订阅更新失败 / 显示"订阅中未发现代理节点"
**常见原因**：
- 订阅链接失效/过期 (机场到期、链接重置)
- 订阅格式不支持 (非标准 Clash/YAML，如 SS/SSR/Vmess 链接列表)
- 机场返回 Base64 编码内容，需解码
- 网络不通 (需代理才能访问订阅链接)

**解决**：
1. 浏览器打开订阅链接确认内容
2. 订阅编辑对话框 → 尝试不同 User-Agent
3. 机场通常提供"一键导入 Clash"链接，优先使用该链接
4. 若机场仅提供 Base64/URI 列表，需用支持 Parser 的客户端 (ClashEdge 内置支持)

### Q21: 节点名乱码 / 显示为空
**原因**：订阅 YAML 编码问题或节点 name 字段缺失。

**解决**：订阅编辑 →「原始编辑」查看原始 YAML，确认 `proxies` 数组中每项都有 `name` 字段。

### Q22: 怎么看订阅剩余流量/到期时间
**位置**：订阅卡片底部显示"用量进度条"和"到期时间" (需机场支持 `Subscription-Userinfo` 头)。

**无数据时**：机场未返回流量信息，无法显示。

### Q23: 如何批量导入多个订阅
**当前版本**：逐个添加。可导出配置后手动合并 YAML 再导入。

### Q24: 订阅节点太多，界面卡顿
**优化**：
- 订阅编辑 → 勾选"仅保留有效节点" (自动过滤信息节点)
- 代理页使用搜索框筛选
- 关闭不需要的策略组自动测速

## ⚙️ 配置与规则

### Q30: 如何自定义规则 / 添加直连域名
**方法 1**：设置 → 高级 → 「Mihomo 配置」直接编辑 `rules` 字段 (需懂 YAML 语法)

**方法 2**：编辑 `Data/rules/` 下对应 `.yaml` 文件 (需禁用自动更新或覆盖后手动同步)

**方法 3**：使用 `rule-providers` 引用外部规则文件 (高级用法)

> **注意**：修改内置规则文件后，自动更新可能覆盖你的修改。建议通过 Mihomo 配置追加自定义规则。

### Q31: 如何让某个应用直连 / 走代理
**进程名规则** (在规则中添加)：
```yaml
PROCESS-NAME,chrome.exe,扶梯出行  # Chrome 走代理
PROCESS-NAME,OneDrive.exe,DIRECT   # OneDrive 直连
```

**注意**：进程名需完全匹配 (含 .exe)，大小写不敏感。

### Q32: DNS 解析异常 / 某些网站打不开
**常见原因**：
- Fake-IP 模式下，部分应用不兼容 (如某些银行、企业内网)
- 上游 DNS 污染/超时

**解决**：
1. 设置 → 代理 → DNS → 关闭"增强模式" 或改为 `redir-host`
2. 设置 → 代理 → DNS → 添加 `fake-ip-filter` 例外域名
3. 尝试不同的 `default-nameserver` (如 `119.29.29.29`, `223.5.5.5`)

### Q33: 如何使用自己的 GeoIP / GeoSite
**设置** → **高级** → **Geo 数据** → 自定义 `geoip-url` / `geosite-url` (需指向 `.dat` 文件直链)。

> 建议使用官方镜像或可靠 CDN，更新间隔建议 ≥ 24 小时。

## 🛡️ 杀毒软件与安全

### Q40: 杀毒软件报毒 / 删除 ClashEdge 文件
**原因**：
- 便携版无数字签名，启动器行为 (解压、重命名、执行) 触发启发式查杀
- mihomo 核心使用 Go 编译，特征码易被误判
- Wintun 驱动未签名 (WireGuard 签名但非 Microsoft 认证)

**解决**：
1. **全盘信任**：将 ClashEdge 目录加入白名单/排除扫描
2. **单文件信任**：对 `ClashEdge.exe`、`App/ClashEdge/clash-edge-core.exe`、`App/ClashEdge/wintun.dll` 分别信任
3. **开发者模式**：Windows 设置 → 更新和安全 → 开发者模式 → 勾选"安装任务" (降低拦截概率)

### Q41: 火绒/360/微信/企业杀毒拦截"修改系统代理"行为
**原因**：修改注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ProxyEnable` 被判定为恶意行为。

**解决**：信任 ClashEdge 进程，或在杀毒软件中添加"允许修改系统代理"规则。

### Q42: 企业环境/管控电脑无法运行
**限制**：
- 组策略禁止修改系统代理
- 禁止安装驱动 (TUN)
- 禁止非受信程序运行
- 网络层拦截代理端口

**建议**：联系 IT 部门申请豁免，或使用便携模式不开启系统代理/TUN，仅作为配置管理工具。

## 📱 Android 专项

### Q50: Android 版能正常用吗？
**现状**：**预览版，无真实代理能力**。仅可体验 UI、VPN 授权流程、订阅导入界面。

**时间表**：见 [`apps/android/README.md`](../apps/android/README.md) 前置条件清单。

### Q51: 安装 APK 提示"解析包失败"
**原因**：
- Android 版本过低 (需 Android 8.0+ / API 26+)
- 架构不匹配 (当前仅提供 arm64-v8a)
- 签名冲突 (已安装其他签名版本)

**解决**：卸载旧版，确认设备架构，重新安装。

## 🔄 更新与维护

### Q60: 怎么知道有新版本？
- 启动时自动静默检查 (可在设置关闭)
- 设置 → 关于 → 「检查更新」
- 关注 [Releases](../../releases) 或 [GitHub Watch](https://github.com/akaspyrean/clashedge/subscription)

### Q61: 更新后配置丢失了？
**便携版不会丢失配置**：Data 文件夹独立于程序文件。

**例外**：手动删除 Data 文件夹、解压时未覆盖模式导致 Data 被移动、启动器回滚异常 (极少见)。

### Q62: 如何备份/迁移配置
**完整迁移**：复制整个 ClashEdge 文件夹到新电脑/新位置。

**仅备份配置**：复制 `Data/` 文件夹 (含 `config.yaml`、`profiles/`、`rules/`、`logs/`)。

### Q63: 规则集多久更新一次？怎么手动更新？
- **自动**：每日 UTC 0:00 后首次启动核心时检查更新
- **手动**：设置 → 代理 → 规则 → 点击「更新规则」 (或重启核心触发)

## 🐛 故障诊断

### 导出诊断包
**位置**：设置 → 关于 → 「导出诊断包」
**包含**：
- 脱敏后的配置 (隐藏订阅 URL token、节点密码)
- 最近 500 行应用日志
- mihomo 核心日志
- 版本信息、运行环境
- 系统代理状态、网络适配器

**用途**：提交 Issue 时附上，开发者可快速定位问题。

### 关键日志位置
| 日志类型 | 位置 |
|----------|------|
| 应用日志 | `Data/logs/clash_edge.log` |
| 核心日志 | `Data/logs/mihomo-<date>.log` |
| 启动器日志 | `Data/logs/launcher.log` (如有) |

### 手动清理缓存/重置
```powershell
# 仅清理规则缓存 (保留配置)
Remove-Item Data/rules/*.yaml -Force

# 完全重置 (删除所有用户数据)
Remove-Item Data/ -Recurse -Force
# 然后重启 ClashEdge.exe
```

## 💡 使用技巧

| 技巧 | 说明 |
|------|------|
| **多订阅切换** | 订阅页点击卡片「使用」按钮，瞬间切换生效配置 |
| **临时直连** | 首页模式切换到「Direct」，所有流量直连 |
| **排查某域名走向** | 连接页搜索域名，查看规则匹配链路 |
| **导出节点列表** | 订阅页 → 卡片菜单 → 「导出」→ 获取纯节点 YAML |
| **多开/多实例** | 复制整个文件夹，修改 `Data/config.yaml` 中端口避免冲突 |
