# 界面使用手册

> 详细介绍各页面功能、操作方法、快捷键。

## 📋 导航栏概览

左侧固定导航栏 (宽屏 232px，窄屏可折叠为 64px)：

| 图标 | 名称 | 路由 | 核心功能 |
|------|------|------|----------|
| 🏠 | **首页** | `/dashboard` | 核心状态、实时流量、快捷切换、当前订阅 |
| 🌐 | **代理** | `/proxies` | 策略组管理、节点选择、测速 |
| 📦 | **订阅** | `/profiles` | 订阅增删改查、导入导出、原始编辑 |
| 📋 | **规则** | `/rules` | 规则集只读查看、搜索筛选 |
| 🔗 | **连接** | `/connections` | 实时流量图、活动连接、连接详情 |
| 📝 | **日志** | `/logs` | 核心日志、级别筛选、正则搜索、导出 |
| ⚙️ | **设置** | `/settings` | 所有配置项分组管理、搜索 |

> **快捷键**：`Ctrl+K` 聚焦当前页搜索框 (代理/订阅/日志/设置页)

## 🏠 首页 - 仪表盘

### 状态核心卡 (左上，占 2/3 宽度)

| 区域 | 功能 | 说明 |
|------|------|------|
| **主连接按钮** (直径 96px) | 启动/停止/重启核心 | 状态色环：灰=停止、蓝=运行中、黄=启动中、红=异常 |
| **状态文字** | 显示详细状态 | "已连接" / "核心已停止" / "启动中…" / "异常: 端口冲突" |
| **版本信息** | mihomo 版本 + 混合端口 | 如 `mihomo 1.19.20 · 混合端口 7890` |
| **操作按钮** | 重启核心 / 重载配置 | 重启=停止后启动；重载=热重载配置不断连接 |

### 代理模式分段控件 (状态核心卡右侧)

| 模式 | 行为 | 适用场景 |
|------|------|----------|
| **Rule** (规则) | 按规则智能分流 | 日常使用，默认模式 |
| **Global** (全局) | 所有流量走"扶梯出行"组 | 需强制代理时 |
| **Direct** (直连) | 所有流量直连 | 排查问题、临时关闭代理 |

### 网络开关 (状态核心卡下方)

| 开关 | 功能 | 说明 |
|------|------|------|
| **系统代理** | 修改 Windows 系统代理设置 | 即时生效，浏览器等应用自动走代理 |
| **TUN 模式** | 创建虚拟网卡透明代理 | 需管理员权限，全系统生效 (含命令行/游戏) |

> **TUN 提权流程**：开启时弹出 UAC，授权后显示"切换中" (黄色 pending 状态)，完成后变蓝；失败自动弹回并 Toast 提示。

### 实时流量卡 (右上，占 1/3 宽度)

- **下载/上传速率**：Display 字号 (40px)，等宽数字
- **迷你趋势图**：`CeSparkline`，60 秒窗口
- **会话统计**：`本次会话 ↓ 1.2 GB · ↑ 345 MB · 23 个活动连接`

### 快捷切换卡 (左下，占 2/3 宽度)

| 元素 | 说明 |
|------|------|
| **策略组下拉** | 默认显示"扶梯出行"当前指向的手动组，可切换 5 个组 |
| **测速按钮** | 对当前组所有节点发起 URL-Test |
| **全部节点** | 跳转到代理页查看完整列表 |
| **节点格网格** | `CeNodeTile` 卡片：名称、协议、延迟标签、点击即选 |

**节点格交互**：
- 悬停：描边加深 + 轻微阴影
- 选中：1.5px 品牌蓝描边 + 右上角勾 + 名称变品牌蓝
- 点击延迟标签：单独重测该节点
- 不可用节点：文字变灰 (disabled 色)

### 订阅卡 + 出口卡 (右下，占 1/3 宽度)

| 信息 | 来源 |
|------|------|
| 订阅名称 | 当前激活订阅 |
| 用量进度条 | `Subscription-Userinfo` 解析 |
| 到期时间 | 同上 |
| 节点数量 | 当前订阅有效节点数 |
| 出口 IP | 有数据源时显示 (需后端支持) |

## 🌐 代理页 - 策略组与节点管理

### 顶部工具栏

| 控件 | 功能 |
|------|------|
| **页面标题** | "代理" |
| **搜索框** (Ctrl+K) | 筛选节点名称/协议/地区 |
| **全部测速** (Primary) | 对当前显示策略组所有节点测速 |
| **刷新图标** | 重新获取节点列表 |
| **代理模式分段控件** | Rule / Global / Direct (同首页) |

### 双栏布局 (宽屏 ≥ 960px)

#### 左栏：策略组列表 (宽 240-300px)

| 列 | 说明 |
|----|------|
| **组名** | 扶梯出行 / 人工智能 / 影音视听 / 人工优选 / 自动优选 |
| **类型标签** | Select / URL-Test (自动优选) |
| **当前节点** | 显示当前选中节点名称 |

**交互**：点击组名 → 右栏显示该组节点；URL-Test 组节点格只读，显示"由测速自动选择"。

#### 右栏：节点格网格

```
repeat(auto-fill, minmax(200px, 1fr))
```

| 筛选/排序 | 说明 |
|-----------|------|
| **地区芯片** | 按节点名/地区关键词筛选 (HK、JP、US、SG、TW 等) |
| **按延迟排序** | 升序/降序切换 |

**窄屏 (< 960px)**：左栏变为顶部横向芯片组，点击切换。

### 模式过滤逻辑

| 模式 | 显示策略组 |
|------|------------|
| **Rule** | 显示 5 个组 (隐藏 GLOBAL) |
| **Global** | 仅显示 GLOBAL 组 |
| **Direct** | 显示空状态："直连模式下无需选择节点" |

## 📦 订阅页 - 订阅全生命周期管理

### 顶部工具栏

| 按钮 | 类型 | 功能 |
|------|------|------|
| **新建配置** | Default | 手动创建空配置 (手写 YAML) |
| **导入/导出 ▾** | Default (下拉) | 导入 YAML/文件 / 导出当前/全部配置 |
| **添加订阅** | **Primary** (唯一) | 打开添加订阅对话框 |

### 卡片网格

`minmax(300px, 1fr)` 自适应网格，每卡片含：

| 字段 | 说明 |
|------|------|
| **名称** | 订阅显示名 |
| **状态标签** | 使用中 (accent) / 即将到期 (warning) / 更新失败 (danger) |
| **URL** | 等宽字体，单行截断，悬停显示完整 |
| **用量进度条** | 下载/上传/总量 (需机场支持) |
| **到期时间** | 同上，无数据则隐藏 |
| **节点数·更新时间** | 如 `42 个节点 · 2 小时前更新` |
| **主操作按钮** | 更新 / 使用 / 原始编辑 (视状态动态) |
| **⋯ 菜单** | 重命名、原始编辑、User-Agent、导出、删除 |

### 添加/编辑订阅对话框

| 字段 | 必填 | 说明 |
|------|------|------|
| **名称** | ✅ | 显示名称 |
| **订阅链接** | ✅ | 支持 http/https/clash/sub/vmess/ss/ssr/trojan/vless/hysteria2/tuic |
| **User-Agent** | ❌ | 自定义 UA，留空使用默认兼容值 |

### 原始编辑对话框

- 代码编辑器 (Monaco/简单 textarea)
- 实时 YAML 语法高亮
- 保存前自动校验基本结构
- **危险操作**：编辑错误可能导致核心启动失败

### 导入/导出

| 操作 | 格式 | 说明 |
|------|------|------|
| **导入配置** | `.yaml` / `.yml` | 合并到现有订阅列表 |
| **导出当前** | `.yaml` | 含节点、策略组、规则的完整配置 |
| **导出全部** | `.zip` | 所有订阅原始内容打包 |
| **导出节点列表** | `.yaml` | 仅 `proxies` 数组，便于分享/备份 |

## 🔗 连接页 - 实时流量监控

### 顶部统计卡片 (4 个数值卡片)

| 指标 | 说明 |
|------|------|
| **下载速率** | 实时 ↓ MB/s |
| **上传速率** | 实时 ↑ MB/s |
| **活动连接** | 当前 ESTABLISHED 连接数 |
| **本次会话流量** | 累计 ↓ / ↑ |

### 流量图 `CeTrafficChart`

- **SVG 手绘**，60 秒滚动窗口
- **下载线**：品牌蓝，线宽 2px，7% 面积填充
- **上传线**：青色，线宽 2px
- **交互**：悬停显示十字线 + Tooltip (数值 + 色点标识系列)
- **操作**：「查看数据表」→ 弹出表格视图

### 连接列表

**分段控件**：「活动」/「已关闭」(如无历史数据仅显示「活动」)

**筛选框**：主机/进程/规则关键词

**表格列**：

| 列 | 说明 |
|----|------|
| **主机·进程** | 目标地址:端口 · 进程名 (PID) |
| **规则 → 链路** | 匹配规则 → 策略组 → 节点 |
| **类型** | TCP / UDP |
| **↓ / ↑** | 该连接下载/上传字节 (等宽) |
| **时长** | 连接持续时间 |
| **断开** | 危险图标按钮，点击确认后强制关闭 |

**操作**：「全部断开…」→ Danger 文字按钮 + `useConfirm` 确认

## 📝 日志页 - 核心日志查看

### 顶部工具栏

| 控件 | 功能 |
|------|------|
| **级别筛选芯片** | DEBUG (无形状) / INFO (圆) / WARN (菱形) / ERROR (横杠) + 计数 |
| **正则搜索框** | 支持 JS 正则，实时高亮匹配行 |
| **暂停/继续** | 切换自动跟随最新日志 |
| **导出** | 下载当前筛选后的日志 `.log` |
| **清空** | 清空内存日志缓冲 (不删除文件) |

### 日志正文

- **字体**：`--ce-font-mono` 13px/20px
- **三列布局**：时间 | 级别色点+文字 | 消息
- **级别色点形状**：
  - DEBUG：无形状 (纯文字)
  - INFO：● 圆 (success 色)
  - WARN：◆ 菱形 (warning 色)
  - ERROR：■ 横杠 (danger 色)
- **自动跟随**：默认开启，向上滚动时暂停，出现"回到最新 ↓"浮动按钮

### 日志来源

- mihomo 核心 stdout/stderr (通过 SSE 流式传输)
- 应用自身日志 (通过 Tauri 日志插件)
- 级别对应：mihomo `error/warning/info/debug` → 应用 `ERROR/WARN/INFO/DEBUG`

## ⚙️ 设置页 - 单页分组 + 搜索

### 顶部搜索栏

- **搜索设置**：输入关键词，匹配项高亮并自动滚动到对应分组
- **清除搜索**：Esc 或点击 ×

### 分组结构 (宽屏两列，窄屏单列)

#### 常规
- 语言、主题 (分段控件：浅色/深色/跟随系统)、启动检查更新、启动更新订阅

#### 代理
- 混合端口、允许局域网、绑定地址、IPv6、运行模式、日志级别、进程探测模式

#### TUN
- 启用、网卡名称、MTU、严格路由、排除路由、DNS 劫持端口、自动安装驱动

#### DNS
- 启用、监听地址、IPv6、增强模式、Fake-IP 网段、Fake-IP 白名单、默认 DNS、上游 DNS、回退 DNS

#### 高级
- Geo 数据模式、加载器、自动更新、更新间隔、自定义 GeoIP/GeoSite/GeoX URL
- 控制器端口、热重载间隔、统计间隔
- **Mixins 编辑器**：YAML 编辑器，实时预览合并结果
- **关于**：版本、构建信息、检查更新、导出诊断包、许可证、第三方声明

### 设置项交互规范

| 类型 | 组件 | 即时生效 |
|------|------|----------|
| 开关 | `ElSwitch` / `CeSwitch` | ✅ |
| 选择器 | `ElSelect` / `CeSegmented` | ✅ (模式) / 🔄 需重启核心 (端口) |
| 输入框 | `ElInput` | 失焦保存 |
| 数字输入 | `ElInputNumber` | 失焦保存 |
| 多行文本 | `ElInput` (textarea) | Ctrl+Enter 保存 |
| 代码编辑 | Monaco/textarea | 手动保存 |

## 🎨 主题与无障碍

### 主题切换

| 模式 | 行为 |
|------|------|
| **浅色** | `--ce-bg-page` = `#F5F6F8` |
| **深色** | `--ce-bg-page` = `#0F1115` |
| **跟随系统** | 读取 `prefers-color-scheme`，系统切换时自动同步 |

**存储**：`localStorage['cfw-theme']`，优先级：用户设置 > 系统偏好 > 默认深色。

### 键盘导航

- `Tab` / `Shift+Tab`：焦点顺序
- `Enter` / `Space`：激活按钮/切换开关/选择项
- `Esc`：关闭对话框/下拉/搜索
- `↑↓←→`：分段控件、列表、表格导航
- `Ctrl+K`：聚焦搜索框

### 焦点指示器

统一焦点环：`2px solid var(--ce-accent-bg)` + `outline-offset: 2px`

### 屏幕阅读器

- 所有图标按钮有 `aria-label`
- 状态变化通过 `aria-live="polite"` 通告
- 延迟标签读屏文案："延迟 86 毫秒，良好"
- 危险操作确认对话框：`role="alertdialog"` + `aria-describedby`

## 💡 进阶操作技巧

### 多订阅快速切换
订阅页 → 点击目标订阅卡片「使用」按钮 → 瞬间生效 (热重载)

### 临时全局/直连
首页模式分段控件 → Global/Direct → 完成后切回 Rule

### 排查某域名走向
连接页搜索域名 → 查看「规则 → 链路」列 → 确认匹配规则与策略组

### 批量测速
代理页 → 选择策略组 → 点击「全部测速」 → 等待完成 → 按延迟排序

### 导出诊断包给开发者
设置 → 关于 → 「导出诊断包」 → 生成 `.zip` 包含脱敏配置、日志、版本信息

### 便携模式多实例
复制整个文件夹 → 修改副本 `Data/config.yaml` 中 `mixed_port`/`controller_port` 避免冲突 → 同时运行
